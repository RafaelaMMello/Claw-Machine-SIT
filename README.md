# 🎰 Gachapon Game

A fun Gachapon-style mini-game built with Python and Pygame, where you can roll for prizes, collect them in your inventory, and see the rarity of each reward!

## 🏆 Features

Gacha Rolling System – Spin for prizes with different rarities:

Common (60%), Rare (30%), Super Rare (8%), Legendary (2%)

Prize Display – Custom names, colors, and images for each prize

Inventory System – Track collected items and points

User Accounts & Guest Mode – Save your progress or play anonymously

Rarity Screen – See the chance of each prize and their category

## 🎮 How to Play

Start the game:

python main.py


Choose Guest or Login/Sign Up.

Click Play to roll the Gachapon.

Collect prizes and see your points in Inventory.

Check Rarity to learn prize probabilities.

## 💻 Installation

Clone the repository:

git clone https://github.com/yourusername/gachapon-game.git
`cd gachapon-game`

Install Pygame:
`pip install pygame`

Run the game:
`python main.py`
